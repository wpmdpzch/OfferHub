# Screenshots

This directory contains product screenshots for the README.

## Required Screenshots

Please add the following screenshots (recommended size: 1200x800px):

- `home.png` — 首页信息流截图
- `search.png` — 搜索结果页截图
- `article.png` — 文章详情页截图
- `write.png` — 发布文章页截图

## How to Take Screenshots

1. Start the project locally: `docker-compose up -d`
2. Navigate to the pages and take screenshots
3. Resize to approximately 1200x800px
4. Save as PNG files in this directory
5. Update the image paths in README.md

## Note

Screenshots are not included in the repository to keep the repository size small.
Please contribute screenshots via PR after the project is set up.
